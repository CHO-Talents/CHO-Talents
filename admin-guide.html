👥 사용자 관리

  1. 관리 > 사용자 관리로 이동합니다.
  2. 사용자 목록은 교사/학생 그룹별로 분리되어 표시됩니다 (각 그룹 PC 10명, 모바일 5명씩 페이징).
  3. 가입 신청이 있으면 신청자의 이름, 부서, 신청 사유를 확인합니다.
  4. 사용자 유형과 권한을 선택한 뒤 승인하거나, 사유를 입력해 거부합니다.
  5. 각 사용자의 관리 ▾ 드롭다운에서 상세 정보, 수정, 부서 이동, 비밀번호 초기화, 삭제를 선택합니다.
  6. 상세 정보에서 아이디, 역할, 권한, 부서, 신청 이력, 달란트 내역, 구매 내역을 확인할 수 있습니다.
부서 이동은 권한에 따라 즉시 처리되거나 승인 요청으로 생성됩니다. 담당 범위 밖의 사용자는 처리 권한이 없을 수 있습니다.

🏢 부서와 관리자 관리

부서 관리

  • 부서명을 등록하거나 설명, 반 개수를 수정합니다.
  • 반 개수가 0이면 반 구분 없이 운영합니다.
  • 관리 드롭다운에서 소속보기, 수정, 삭제를 선택합니다.

관리자 관리

  • 기존 교사 사용자를 검색해 운영 권한을 부여합니다.
  • 권한과 소속 부서, 담당 관리 부서를 지정합니다.
  • 본인보다 높은 권한은 수정할 수 없습니다.

🎫 달란트 QR 관리

  1. 달란트 > 달란트 QR 관리로 이동합니다.
  2. 지급 대상이 학생인지 교사인지 선택합니다.
  3. 달란트 항목을 선택하거나 직접 설명과 금액을 입력합니다.
  4. 지급 제한 없음 또는 선착순 지급 인원을 선택합니다.
  5. 유효 기간을 지정일, 기간, 무기한 중에서 선택합니다.
  6. 필요하면 위치 제한을 켜고 카카오맵 주소 검색으로 장소와 반경을 지정합니다.
  7. QR 코드를 생성한 뒤 인쇄하거나, 수령자 목록을 확인합니다.
QR을 수정하면 기존 코드 값을 그대로 고치는 것이 아니라 새 QR 코드가 만들어집니다. 이미 배포한 QR을 바꿀 때는 새 코드로 다시 안내하세요.

🛒 상품과 구매 관리

상품 관리

  • 교사용/학생용 그룹별로 상품이 분리 표시됩니다(모바일 10개/PC 20개 페이징).
  • 상품명, 카테고리, 가격, 설명, 이미지 또는 이모지를 입력합니다.
  • 관리 드롭다운에서 수정 또는 삭제를 선택합니다.

구매 관리

  • 상태별 탭을 선택하면 상품별 합계와 일괄 처리 버튼이 표시됩니다.
  • 부서와 기간 필터로 필요한 주문만 조회합니다.
  • 관리 드롭다운에서 상태 변경이나 되돌리기를 선택합니다.
  • 구매 확정 단계에서 달란트가 실제 차감됩니다.

🔐 관리자 전용 설정

📊 활동 로그 (한글화)

모든 활동 로그의 액션 이름이 한글로 표시됩니다.

1 운영 → 로그에서 활동 로그를 확인합니다.
2 액션 열에 한글 라벨이 표시되며, 영문 키는 작은 글씨로 병기됩니다.
3 상세 내역의 키도 한글로 표시됩니다 (대상, 변경내역, 오류 등).

미확인 ERROR 이상 로그는 확인 완료 처리를 남겨야 합니다. 삭제는 삭제 대기 방식으로 처리됩니다.

📋 작업 이력 (개편)

모든 관리 작업이 한글 상세 내역으로 기록됩니다.

1 운영 → 작업 이력에서 10개 카테고리 필터로 조회합니다.
2 필터: 사용자/등록/부서/달란트/상품·주문/Q&A/인증/로그관리/권한·설정
3 각 작업의 변경내역이 한글로 상세히 기록됩니다 (예: "이름: 홍길동, 부서: 1부서 → 2부서").

페이지 접근

권한별로 어떤 페이지와 화면 요소를 사용할 수 있는지 설정합니다.

페이지 기능

권한별 기능 사용 설정값을 관리합니다. 실제 적용 범위는 각 화면의 권한 로직과 함께 동작합니다.

⭐ 메인 페이지 바로가기

⭐ 즐겨찾기 설정

메인 페이지의 바로가기 카드를 내가 원하는 메뉴로 설정할 수 있습니다.

1 메인 페이지에서 ⭐ 즐겨찾기 설정 버튼을 누릅니다.
2 표시할 바로가기를 선택하고 저장을 누릅니다.
3 설정은 계정에 저장되어 다른 기기에서도 동일하게 표시됩니다.

✅ 운영할 때 기억할 점

  • 비밀번호는 확인할 수 없고, 필요한 경우 1234로 초기화만 할 수 있습니다.
  • 구매 신청은 바로 차감이 아니며, 구매 확정 시점에 달란트가 차감됩니다.
  • 권한이 낮은 계정은 일부 버튼이 보이지 않거나, 보이더라도 처리 권한이 제한될 수 있습니다.
  • 삭제 대기 처리된 로그나 상품은 일반 목록에서 숨겨지지만 기록은 남습니다.
  • QR 위치 제한을 쓰려면 사용자가 수령할 때 브라우저 위치 권한을 허용해야 합니다.
