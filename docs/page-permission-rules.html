CHO-Talents 페이지별 권한 설정 정리

실제 소스 코드(initPage, data-min-perm, JS 조건문)에서 추출한 권한 설정입니다. v3.40.0 기준 (2026-06-13)

1. 권한 등급 체계

0 비로그인 20 학생 40 일반 교사 60 부서 담당 교사 70 구매 담당 교사 80 부장 교사 90 전도사님 100 관리자

auth.js의 initPage(minRank) 함수가 페이지 접근을 제어하고, applyPermNav(rank) 함수가 data-min-perm 속성 기준으로 내비게이션 메뉴를 표시/숨김 처리합니다.

2. 내비게이션 메뉴 (data-min-perm)

applyPermNav(rank) 함수가 rank 기준으로 메뉴 표시/숨김 처리합니다. "내 달란트", "내 구매 상품"은 로그인 시 JS로 별도 표시됩니다.
