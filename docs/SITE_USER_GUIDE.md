# ⭐ 달란트 마을 사이트 안내서

이 문서는 개발자가 아닌 일반 사용자가 `CHO-Talents` 사이트를 쉽게 이용할 수 있도록 정리한 안내서입니다.

**사이트 주소:** https://cho-talents.github.io/CHO-Talents/

## 1. 달란트 마을에서 할 수 있는 일

| 사용자 | 할 수 있는 일 |
|---|---|
| 학생 | 내 달란트 잔액과 적립/사용 내역 확인, 학생용 상점 상품 확인, 상품 구매 신청 |
| 교사 | 내 달란트 확인, 교사용/학생용 상점 상품 확인, 상품 구매 신청 |
| 부서 담당 교사 | 학생/교사 관리, 달란트 지급/사용 처리, 상품 관리, 구매 신청 처리 |
| 부장 교사/전도사님/관리자 | 부서, 사용자, 관리자, 상품, 구매, 보고서, 로그 등 운영 관리 |
| 비로그인 사용자 | 메인 화면, 달란트 적립 안내, 학생용 상점, 계정 등록 신청 |

## 2. 처음 이용하는 방법

1. 사이트에 접속합니다.
2. 계정이 있으면 `로그인`을 누릅니다.
3. 계정이 없으면 `계정 등록 신청`을 누릅니다.
4. 아이디 중복확인, 이름, 소속 부서를 입력하고 신청합니다.
   - 아이디는 영문/숫자/`_`/`-`만 사용할 수 있습니다 (한글 불가).
5. 관리자가 승인하면 초기 비밀번호 `1234`로 로그인할 수 있습니다.
6. 첫 로그인 때는 반드시 새 비밀번호로 변경해야 합니다.

## 3. 로그인 후 이동하는 화면

로그인하면 내 권한에 맞는 화면으로 자동 이동합니다.

| 권한 | 처음 이동하는 곳 |
|---|---|
| 관리자 / 전도사님 / 부장 교사 | 대시보드 |
| 부서 담당 교사 / 일반 교사 | 달란트 관리 |
| 학생 | 내 달란트 |

첫 로그인 상태라면 어떤 권한이든 먼저 `비밀번호 변경` 화면으로 이동합니다.

상단 네비게이션에는 `⭐ 달란트 마을` 브랜드와 함께 내 이름(아이디)과 권한이 표시됩니다.

## 4. 학생 이용 안내

학생은 주로 아래 메뉴를 사용합니다.

| 메뉴 | 설명 |
|---|---|
| 달란트 적립 | 어떤 활동으로 달란트를 받을 수 있는지 확인합니다. |
| 상품 구매 | 학생용 달란트 상점 상품과 필요한 달란트를 확인합니다. 로그인하면 구매 신청을 할 수 있습니다. |
| 내 달란트 | 누적 적립, 사용 완료, 사용 대기, 사용 가능 달란트, 최근 내역을 확인합니다. |

### 상품 구매하기

1. `상품 구매` 페이지에서 원하는 상품의 `구매 신청` 버튼을 누릅니다.
2. 확인 창에서 `확인`을 누르면 구매 신청이 완료됩니다.
3. 신청한 달란트는 바로 차감되지 않고 `사용 대기` 상태로 표시됩니다.
4. `내 달란트`에서 `사용 대기 달란트`와 실제 `사용 가능 달란트`를 확인할 수 있습니다.
5. 선생님이 상품을 구매하여 지급하면 실제로 달란트가 차감됩니다.

구매 진행 단계: `구매 신청` → `상품 준비` → `상품 구매(달란트 차감)` → `상품 지급`

## 5. 교사 이용 안내

교사는 `내 달란트`에서 본인 달란트 내역을 확인할 수 있습니다.

`상품 구매`에서는 교사용 상품과 학생용 상품을 탭으로 나누어 볼 수 있습니다. 교사로 로그인하면 교사용 탭이 기본으로 선택됩니다.

교사도 학생과 마찬가지로 `구매 신청` 버튼으로 상품 구매를 신청할 수 있습니다.

일반 교사는 담당 부서/반의 학생 달란트 지급/사용 처리가 가능합니다.

## 6. 운영자 이용 안내

부서 담당 교사 이상은 상단 메뉴에 관리 기능이 추가로 보입니다. 보이는 메뉴는 권한에 따라 다릅니다.

| 메뉴 | 사용 목적 |
|---|---|
| 사용자 관리 | 학생/교사 목록 확인, 사용자 수정, 가입 신청 처리, 부서 이동 관리 |
| 달란트 관리 | 학생/교사에게 달란트 항목별 일괄 지급, 수동 적립/사용/반환 처리 |
| 상품 관리 | 상점 상품 등록, 수정, 이미지 업로드, 재고 관리 |
| 구매 관리 | 상품 구매 신청 목록 확인, 상품 준비/구매/지급 단계 처리 |
| 대시보드 | 전체 현황, 가입 대기자, 오류 로그 요약 확인 |
| 부서 관리 | 부서 생성, 수정, 비활성화, 부서별 인원 확인 |
| 관리자 관리 | 기존 사용자에게 운영 권한 부여 또는 수정 |
| 보고서 | 작업 보고서 확인 및 등록 |
| 로그 | 오류나 주요 활동 내역 확인 및 완료 처리, 삭제 대기 관리 |
| 페이지 접근 | 권한별로 어떤 페이지에 접근할 수 있는지 설정 |
| 페이지 기능 | 권한별로 어떤 기능(수정/삭제/승인)을 사용할 수 있는지 설정 |
| 작업 이력 | 사용자 정보 수정, 부서 변경, 비밀번호 초기화 등 관리 작업 이력 확인 |
| 버전 | 사이트 변경 이력 확인 |

### 달란트 지급하기

1. `달란트 관리`에서 학생/교사 탭을 선택합니다.
2. 대상 사용자를 선택합니다.
3. 지급 항목에서 지급할 항목의 체크박스를 선택합니다.
   - 이미 오늘(또는 이번 주) 지급된 항목은 자동 표시됩니다.
4. `지급 확정` 버튼을 누르면 선택한 항목이 일괄로 지급됩니다.
5. 수동으로 금액과 사유를 직접 입력하여 적립/사용할 수도 있습니다.

### 달란트 반환

부장 교사 이상 권한자는 이미 지급된 달란트를 반환할 수 있습니다.

1. 대상 사용자의 `상세` 버튼을 눌러 달란트 내역을 확인합니다.
2. 반환 사유를 입력하고 반환 처리합니다.
3. 단, 잔여 달란트가 0보다 작아질 수 없습니다.

### 부서 이동

사용자의 소속 부서를 변경하려면 `사용자 관리`의 `부서 이동` 기능을 사용합니다.

- 전도사님/관리자: 즉시 이동 처리 가능
- 부장 교사/부서 담당 교사: 부서 이동 요청만 가능 (전도사님 이상이 승인)

### 구매 관리

구매 관리 페이지에서 상품 구매 신청을 처리합니다.

| 단계 | 설명 |
|---|---|
| 구매 신청 | 학생/교사가 상점에서 신청. 달란트는 아직 차감되지 않음 |
| 상품 준비 | 담당 교사가 신청을 확인하고 상품 준비 상태로 변경 |
| 상품 구매 | 관리자가 실제로 상품을 구매한 후 확정. 이때 달란트가 차감됨 |
| 상품 지급 | 상품을 실제로 전달한 후 지급 완료 처리 (일괄 처리 가능) |

## 7. 달란트는 어떻게 반영되나요?

1. 학생이나 교사가 활동을 합니다.
2. 선생님 또는 운영자가 `달란트 관리`에서 대상자를 선택합니다.
3. 지급 항목의 체크박스를 선택하고 `지급 확정`을 누르거나, 사유와 금액을 직접 입력합니다.
4. 처리 후 사용자의 `내 달란트` 화면에 잔액과 내역이 표시됩니다.
5. 상품 교환 시에는 `상품 구매` 페이지에서 구매 신청을 하면 운영자가 처리합니다.

## 8. 내 달란트 화면 보는 방법

| 항목 | 의미 |
|---|---|
| 누적 달란트 | 지금까지 받은 달란트 합계 |
| 사용 완료 달란트 | 실제로 사용 처리된 달란트 |
| 사용 대기 달란트 | 구매 신청했지만 아직 확정되지 않은 달란트 |
| 사용 가능 달란트 | 실제로 사용할 수 있는 잔여 달란트 (잔여 - 사용 대기) |

## 9. 비밀번호와 계정

- 가입 승인 후 초기 비밀번호는 `1234`입니다.
- 첫 로그인 시 새 비밀번호로 변경해야 합니다.
- 비밀번호를 잊은 경우 담당 선생님이나 관리자에게 초기화를 요청하세요.
- 초기화 후 다시 `1234`로 로그인하고 새 비밀번호로 변경하면 됩니다.

## 10. 자주 묻는 질문

| 질문 | 답변 |
|---|---|
| 로그인이 안 돼요. | 아이디와 비밀번호를 다시 확인하세요. 승인 전 계정은 로그인할 수 없으며, "승인 대기 중" 안내가 표시됩니다. |
| 계정 신청 후 바로 사용할 수 있나요? | 아니요. 관리자가 승인한 뒤 사용할 수 있습니다. |
| 상품은 어떻게 구매하나요? | 로그인 후 `상품 구매` 페이지에서 `구매 신청` 버튼을 누르세요. 이후 선생님이 처리합니다. |
| 구매 신청했는데 달란트가 안 줄었어요. | 정상입니다. 구매 신청 시에는 `사용 대기`로 표시되고, 선생님이 상품 구매를 확정하면 실제로 차감됩니다. |
| 내 달란트가 맞지 않는 것 같아요. | 담당 선생님에게 문의해 최근 적립/사용 내역을 확인하세요. |
| 교사용 상품이 안 보여요. | 교사 계정으로 로그인해야 교사용 상품 탭을 볼 수 있습니다. |
| 메뉴가 사람마다 달라요. | 사이트 권한에 따라 사용할 수 있는 메뉴만 보입니다. |
| 오류 메시지가 표시돼요. | 에러는 한글로 안내됩니다. 같은 오류가 반복되면 관리자에게 문의하세요. |

## 11. 개인정보와 이용 기록

사이트 운영과 오류 확인을 위해 로그인, 페이지 방문, 오류 발생, 관리 작업 같은 활동 기록이 저장될 수 있습니다. 오류 확인용 로그에는 브라우저, 기기 종류, 화면 크기, IP 등 접속 환경 정보가 함께 남을 수 있습니다.

비밀번호는 사이트 화면에 표시되지 않으며, 담당자도 기존 비밀번호를 확인할 수 없습니다. 필요한 경우 새 초기 비밀번호로 재설정만 할 수 있습니다.

다른 사용자의 아이디는 관리자를 제외하고 화면에 표시되지 않습니다.
