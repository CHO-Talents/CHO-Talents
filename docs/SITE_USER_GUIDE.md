# ⭐ 달란트 마을 사이트 안내서

이 문서는 개발자가 아닌 일반 사용자가 `CHO-Talents` 사이트를 쉽게 이용할 수 있도록 정리한 안내서입니다. 사이트의 `소개` 메뉴에는 역할별로 `사용자 가이드`, `교사 가이드`, `관리자 가이드`가 나뉘어 있습니다.

**사이트 주소:** https://cho-talents.github.io/CHO-Talents/

## 1. 달란트 마을에서 할 수 있는 일

| 사용자 | 할 수 있는 일 |
|---|---|
| 학생 | 내 달란트 잔액과 적립/사용 내역 확인, 학생용 상점 상품 확인, 상품 구매 신청, 내 구매 상품 확인, Q&A 질문 |
| 교사 | 내 달란트 확인, 교사용/학생용 상점 상품 확인, 상품 구매 신청, 권한 범위 내 학생 대리 구매 |
| 부서 담당 교사 | 담당 부서 학생/교사 관리, 달란트 지급/사용 처리, 상품 관리, 구매 신청 처리, Q&A 답변 |
| 부장 교사/전도사님/관리자 | 부서, 사용자, 관리자, 상품, 구매, 보고서, 버전, 로그 등 운영 관리 |
| 비로그인 사용자 | 메인 화면, 사용자 가이드, 달란트 적립 안내, Q&A FAQ, 학생용 상점, 계정 등록 신청 |

## 2. 처음 이용하는 방법

1. 사이트에 접속합니다.
2. 계정이 있으면 `로그인`을 누릅니다.
3. 계정이 없으면 `계정 등록 신청`을 누릅니다.
4. 아이디 중복확인, 이름, 소속 부서를 입력하고 신청합니다.
   - 아이디는 영문/숫자/`_`/`-`만 사용할 수 있습니다 (한글 불가).
5. 관리자가 승인하면 초기 비밀번호 `1234`로 로그인할 수 있습니다.
6. 첫 로그인 때는 반드시 새 비밀번호로 변경해야 합니다.

## 3. 로그인 후 이동하는 화면

로그인하면 모든 사용자가 먼저 `메인` 화면으로 이동합니다. 이후 상단 메뉴에서 내 권한에 맞는 기능만 볼 수 있습니다.

첫 로그인 상태라면 어떤 권한이든 먼저 `비밀번호 변경` 화면으로 이동합니다. 새 비밀번호로 변경한 뒤 다시 메인 화면과 권한별 메뉴를 사용할 수 있습니다.

상단 네비게이션에는 `⭐ 달란트 마을` 브랜드와 함께 소개, 달란트, 상품, 관리, 운영 메뉴가 표시됩니다. 로그인 상태와 권한에 따라 메뉴 항목이 자동으로 달라집니다.

## 4. 학생 이용 안내

학생은 주로 아래 메뉴를 사용합니다.

| 메뉴 | 설명 |
|---|---|
| 달란트 적립 | 어떤 활동으로 달란트를 받을 수 있는지 확인합니다. |
| 상품 구매 | 학생용 달란트 상점 상품과 필요한 달란트를 확인합니다. 로그인하면 구매 신청을 할 수 있습니다. |
| 내 달란트 | 누적 적립, 사용 완료, 사용 대기, 사용 가능 달란트, 최근 내역을 확인합니다. |
| 내 구매 상품 | 내가 신청한 상품의 진행 상태를 확인합니다. |
| Q & A | 자주 묻는 질문을 보고, 로그인 후 궁금한 내용을 질문할 수 있습니다. |

### 상품 구매하기

1. `상품 구매` 페이지에서 원하는 상품의 `구매 신청` 버튼을 누릅니다.
2. 확인 창에서 `확인`을 누르면 구매 신청이 완료됩니다.
3. 신청한 달란트는 바로 차감되지 않고 `사용 대기` 상태로 표시됩니다.
4. `내 달란트`에서 `사용 대기 달란트`와 실제 `사용 가능 달란트`를 확인할 수 있습니다.
5. `내 구매 상품`에서 신청한 상품의 진행 상태를 확인할 수 있습니다.
6. 선생님이 상품 구매를 확정하면 실제로 달란트가 차감되고, 지급 완료 상태까지 확인할 수 있습니다.

구매 진행 단계: `구매 신청` → `상품 준비` → `상품 구매 확정(달란트 차감)` → `상품 지급`

## 5. 교사 이용 안내

교사는 `내 달란트`에서 본인 달란트 내역을 확인할 수 있습니다.

`상품 구매`에서는 교사용 상품과 학생용 상품을 탭으로 나누어 볼 수 있습니다. 교사로 로그인하면 교사용 탭이 기본으로 선택됩니다.

교사는 **교사용 상품만** 직접 구매 신청할 수 있으며, 학생용 상품은 조회만 가능합니다(대리 구매를 위해 가격과 재고 확인).

일반 교사는 담당 부서/반의 학생 달란트 지급/사용 처리가 가능합니다. 권한이 있으면 `상품 구매` 화면에서 `대리 구매` 기능으로 담당 범위 안의 학생을 선택해 학생용 상품을 구매 신청할 수 있습니다. 대리 구매 시 선택한 사용자의 유형(학생/교사)에 맞는 상품만 표시됩니다.

카테고리 필터와 상품명/카테고리 검색으로 원하는 상품을 빠르게 찾을 수 있습니다.

## 6. 운영자 이용 안내

부서 담당 교사 이상은 상단 메뉴에 관리 기능이 추가로 보입니다. 보이는 메뉴는 권한에 따라 다릅니다.

| 메뉴 | 사용 목적 |
|---|---|
| 사용자 관리 | 학생/교사 목록 확인, 사용자 수정, 가입 신청 처리, 부서 이동 관리 |
| 달란트 관리 | 학생/교사에게 달란트 항목별 일괄 지급, 출석 버튼(즉시 지급). 수동 적립은 관리자(100+)만 가능. 사용 기능 제거됨 |
| 달란트 QR 관리 | QR 코드 생성(2차원 이미지), 수정(새 코드 재생성), 비활성화. 지급 대상(학생/교사) 구분, 유효기간(지정일/기간/무기한) 라디오, 위치 제한(카카오맵 주소 검색, 반경 500m~5km). 인쇄 시 QR 이미지 출력 |
| 달란트 통계 | 누적 적립 통계를 전체/부서별/사용자별/유형별로 확인. 전체/학생/교사 라디오 필터, 부서 필터, 기간 프리셋(오늘/1주/1달/1년) 제공. 유형별은 학생/교사 각각 항목별 비율 표시 |
| 상품 관리 | 상점 상품 등록, 수정, 이미지 업로드. 삭제 버튼은 삭제 대기(소프트 삭제)로 목록에서 숨김 처리 |
| 구매 관리 | 상품 구매 신청 목록 확인, 모든 상태 탭에 날짜/부서 필터(기본 오늘) + 기간 프리셋(오늘/1주/1달/1년), 상품 준비/구매/지급 단계 처리, 단계 되돌리기(↩) |
| 대시보드 | 부장 교사 이상이 전체 현황과 가입 대기자를 확인. 미확인 ERROR+ 카드는 관리자(100+)만 표시(클릭 시 로그 이동). 바로가기에 달란트 통계/QR 관리 포함 |
| 부서 관리 | 부서 생성, 수정, 비활성화, 부서별 인원 확인 |
| 관리자 관리 | 기존 사용자에게 운영 권한 부여 또는 수정 |
| 질문 관리 | Q&A 페이지에서 사용자 질문에 댓글(답변) 등록, FAQ 등록/직접 추가, 90+ 삭제 |
| 보고서 | 작업 보고서 확인 및 등록 |
| 로그 | 관리자(100+)가 오류나 주요 활동 내역 확인 및 완료 처리, 삭제 대기 관리. 기간 필터 기본값 오늘 + 기간 프리셋(오늘/1주/1달/1년) |
| 페이지 접근 | 관리자(100+)가 권한별 페이지 접근과 요소 표시를 설정 |
| 페이지 기능 | 관리자(100+)가 권한별 기능 설정값을 관리 |
| 작업 이력 | 관리자(100+)가 관리 작업 이력 확인. 기간 필터 기본값 오늘 + 기간 프리셋(오늘/1주/1달/1년), 페이지 로드 시 자동 조회 |
| 버전 | 사이트 변경 이력 확인 |

### 달란트 지급하기

1. `달란트 관리`에서 학생/교사 탭을 선택합니다.
2. 대상 사용자를 선택합니다.
3. **출석 버튼**: 각 사용자 행의 `출석` 버튼을 클릭하면 출석 달란트가 즉시 지급됩니다.
   - 당일 이미 지급된 경우 버튼이 비활성화(`✓출석`)로 표시됩니다.
   - '달란트 지급' 모달에서 출석 항목과 동일하게 처리됩니다.
4. **항목 선택 지급**: `달란트 지급` 버튼을 눌러 지급 항목 체크박스를 선택합니다.
   - 이미 오늘(또는 이번 주) 지급된 항목은 자동 표시됩니다.
5. `지급 확정` 버튼을 누르면 선택한 항목이 일괄로 지급됩니다.
6. 수동으로 금액과 사유를 직접 입력하여 적립/사용할 수도 있습니다.

### 달란트 반환

부장 교사 이상 권한자는 이미 지급된 달란트를 반환할 수 있습니다.

1. 대상 사용자의 `상세` 버튼을 눌러 달란트 내역을 확인합니다.
2. 반환 사유를 입력하고 반환 처리합니다.
3. 단, 잔여 달란트가 0보다 작아질 수 없습니다.

### 부서 이동

사용자의 소속 부서를 변경하려면 `사용자 관리`의 `부서 이동` 기능을 사용합니다.

- 전도사님 이상: 즉시 이동 또는 전체 요청 처리 가능
- 부장 교사: 전체 요청을 볼 수 있고, 담당 관리 부서 요청을 처리 가능
- 부서 담당 교사: 담당 부서 범위에서 요청/처리 가능

### 달란트 QR 관리

전도사님(90등급) 이상이 QR 코드를 생성하고 관리할 수 있습니다.

1. `달란트 QR 관리` 페이지에서 **지급 대상**(학생/교사)을 선택합니다. 선택에 따라 해당 대상에게 지급 가능한 달란트 항목만 표시됩니다.
2. 달란트 항목을 선택하거나, "직접 입력"으로 설명과 금액을 입력합니다.
3. **유효 기간**을 라디오 버튼으로 선택합니다:
   - `지정일`: 선택한 날짜 하루 동안만 유효 (00:00 ~ 23:59)
   - `기간`: from ~ to 기간 동안 유효
   - `무기한`: 기간 제한 없이 사용 가능
4. **위치 제한**을 설정할 수 있습니다:
   - `제한 없음`: 어디서나 수령 가능
   - `특정 위치`: 카카오맵으로 주소를 검색/선택하고, 반경(500m~5km)을 지정합니다. 해당 범위 안에서만 QR 수령이 가능합니다.
5. `🎫 QR 코드 생성` 버튼을 눌러 QR 코드를 생성합니다.
6. 생성된 QR 코드는 2차원 이미지로 표시됩니다. `인쇄` 버튼으로 QR 이미지를 출력할 수 있습니다.
7. `수정` 버튼으로 대상, 항목, 유효 기간, 위치 제한을 변경할 수 있으며, 저장 시 새로운 QR 코드가 생성됩니다.
8. `복사` 버튼(관리자만 표시)으로 코드 텍스트를 복사할 수 있습니다.

### 구매 관리

구매 관리 페이지에서 상품 구매 신청을 처리합니다. 모든 상태 탭(전체/구매신청/상품준비/상품구매/상품지급)에서 날짜(from~to), 부서 필터, 기간 프리셋(오늘/1주/1달/1년)으로 원하는 주문만 조회할 수 있습니다.

| 단계 | 설명 |
|---|---|
| 구매 신청 | 학생/교사가 상점에서 신청. 달란트는 아직 차감되지 않음 |
| 상품 준비 | 담당 교사가 신청을 확인하고 상품 준비 상태로 변경 |
| 상품 구매 | 처리 권한자가 실제 구매를 확정. 이때 달란트가 차감됨 |
| 상품 지급 | 상품을 실제로 전달한 후 지급 완료 처리 (일괄 처리 가능) |

## 7. 달란트는 어떻게 반영되나요?

1. 학생이나 교사가 활동을 합니다.
2. 선생님 또는 운영자가 `달란트 관리`에서 대상자를 선택합니다.
3. 지급 항목의 체크박스를 선택하고 `지급 확정`을 누르거나, 사유와 금액을 직접 입력합니다.
4. 처리 후 사용자의 `내 달란트` 화면에 잔액과 내역이 표시됩니다.
5. 상품 교환 시에는 `상품 구매` 페이지에서 구매 신청을 하면 운영자가 처리합니다.

## 8. 내 달란트 화면 보는 방법

| 항목 | 의미 |
|---|---|
| 누적 달란트 | 지금까지 받은 달란트 합계 |
| 사용 완료 달란트 | 실제로 사용 처리된 달란트 |
| 사용 대기 달란트 | 구매 신청했지만 아직 확정되지 않은 달란트 |
| 사용 가능 달란트 | 실제로 사용할 수 있는 잔여 달란트 (잔여 - 사용 대기) |

`내 구매 상품` 화면에서는 내가 신청한 상품의 현재 단계를 확인할 수 있습니다. 단계는 `구매 신청`, `상품 준비`, `상품 구매`, `상품 지급` 순서로 표시됩니다.

## 9. 비밀번호와 계정

- 가입 승인 후 초기 비밀번호는 `1234`입니다.
- 첫 로그인 시 새 비밀번호로 변경해야 합니다.
- **비밀번호 규칙**: 8자 이상, 영문과 숫자를 반드시 포함해야 합니다.
- 초기 비밀번호 `1234`는 새 비밀번호로 사용할 수 없습니다.
- 비밀번호를 잊은 경우 담당 선생님이나 관리자에게 초기화를 요청하세요.
- 초기화 후 다시 `1234`로 로그인하고 새 비밀번호로 변경하면 됩니다.

## 10. Q&A와 자주 묻는 질문

자주 묻는 질문은 [Q & A 페이지](https://cho-talents.github.io/CHO-Talents/qna.html)에서 확인할 수 있습니다.

- 비로그인 사용자는 공개 FAQ를 볼 수 있고, 이름을 입력하여 질문 등록도 가능합니다.
- 로그인 사용자는 새 질문을 등록할 수 있습니다.
- 부서 담당 교사 이상은 질문에 댓글(답변)을 달 수 있고, 필요한 질문을 FAQ로 등록할 수 있습니다.
- 관리자는 FAQ 항목을 직접 추가할 수 있습니다 (FAQ 직접 등록 버튼).
- 전도사님(90+) 이상은 등록된 질문을 삭제할 수 있습니다.

| 질문 | 답변 |
|---|---|
| 로그인이 안 돼요. | 아이디와 비밀번호를 다시 확인하세요. 승인 전 계정은 로그인할 수 없으며, "승인 대기 중" 안내가 표시됩니다. |
| 계정 신청 후 바로 사용할 수 있나요? | 아니요. 관리자가 승인한 뒤 사용할 수 있습니다. |
| 상품은 어떻게 구매하나요? | 로그인 후 `상품 구매` 페이지에서 `구매 신청` 버튼을 누르세요. 이후 선생님이 처리합니다. |
| 구매 신청했는데 달란트가 안 줄었어요. | 정상입니다. 구매 신청 시에는 `사용 대기`로 표시되고, 선생님이 상품 구매를 확정하면 실제로 차감됩니다. |
| 내 달란트가 맞지 않는 것 같아요. | 담당 선생님에게 문의해 최근 적립/사용 내역을 확인하세요. |
| 교사용 상품이 안 보여요. | 교사 계정으로 로그인해야 교사용 상품 탭을 볼 수 있습니다. |
| 메뉴가 사람마다 달라요. | 사이트 권한에 따라 사용할 수 있는 메뉴만 보입니다. |
| 오류 메시지가 표시돼요. | 에러는 한글로 안내됩니다. 같은 오류가 반복되면 관리자에게 문의하세요. |
| 비밀번호를 잊어버렸어요. | 담당 선생님에게 초기화를 요청하세요. 초기화 후 1234로 로그인하고 새 비밀번호로 변경하면 됩니다. |

## 11. 네비게이션 메뉴 구조

사이트 상단 네비게이션은 드롭다운 방식으로 구성되어 있습니다. 각 메뉴 그룹을 클릭하면 하위 메뉴가 펼쳐지고, 다른 곳을 클릭하면 닫힙니다. 데스크탑에서는 마우스를 올려도(hover) 메뉴가 열립니다.

| 그룹 | 메뉴 항목 | 접근 권한 |
|------|-----------|-----------|
| 소개 | 사용자 가이드, 교사 가이드, 관리자 가이드, 달란트 적립, Q & A | 사용자 가이드는 모든 사용자, 교사 가이드는 일반 교사(40)+, 관리자 가이드는 부서 담당 교사(60)+ |
| 달란트 | 내 달란트, 달란트 관리 | 로그인 사용자 / 일반 교사(40)+ |
| 상품 | 상품 구매, 내 구매 상품, 상품 관리, 구매 관리 | 모든 사용자 / 로그인 사용자 / 부서 담당 교사(60)+ |
| 관리 | 사용자 관리, 부서 관리, 질문 관리, 대시보드, 관리자 관리 | 사용자/부서/질문은 부서 담당 교사(60)+, 대시보드/관리자는 부장 교사(80)+ |
| 운영 | 페이지 접근, 페이지 기능, 버전, 보고서, 작업 이력, 로그 | 보고서·버전은 부장 교사(80)+, 나머지는 관리자(100)+ |

## 12. 개인정보와 이용 기록

사이트 운영과 오류 확인을 위해 로그인, 페이지 방문, 오류 발생, 관리 작업 같은 활동 기록이 저장될 수 있습니다. 오류 확인용 로그에는 브라우저, 기기 종류, 화면 크기, IP 등 접속 환경 정보가 함께 남을 수 있습니다.

비밀번호는 사이트 화면에 표시되지 않으며, 담당자도 기존 비밀번호를 확인할 수 없습니다. 필요한 경우 새 초기 비밀번호로 재설정만 할 수 있습니다.

다른 사용자의 아이디는 관리자를 제외하고 화면에 표시되지 않습니다.
